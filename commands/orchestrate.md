# /orchestrate — Hand a complex task to the Master Orchestrator for full coordination.

Pass this task to @master-orchestrator for full multi-agent coordination.

The orchestrator will:
1. **Analyse** the task: domain, risk level, ambiguities
2. **Select** the right specialist agents from the 52-agent roster
3. **Sequence** their involvement in dependency order (plan → design → implement → review → test → release)
4. **Parallelize** independent work where possible
5. **Enforce quality gates** before declaring any phase complete
6. **Escalate** to you immediately if a blocker requires human decision

## Before starting, the orchestrator will clarify:
- Is this greenfield or modifying existing code?
- What is the target stack? (node / python / dotnet / other)
- What is the risk level? (internal tool / production service / security-critical)
- Is there a deadline or hard constraint to factor in?
