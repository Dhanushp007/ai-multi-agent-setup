# /review — Reviews the current diff or selected code for issues.

Review the selected code or current diff:
- Check for bugs, logic errors, and security issues — not style
- Flag anything that would fail in production or edge cases
- Note any missing error handling, null checks, or resource cleanup
- Group findings: 🔴 Must fix | 🟡 Should fix | 🔵 Consider
- Keep feedback specific with line references
- End with: "Looks good to merge" or a one-line summary of blockers
